# Corporate track: cost cards

For hospital-issued devices using Microsoft 365 Copilot, Pair and Agentsea.

Checked on 3 October 2026 against public sources only. Internal quotas, data
rules and local settings are not public: every TODO below needs an answer from
your institution. Times are estimates until measured.

First, find out which Copilot you have. The label inside the app tells you:
"Copilot Chat (Basic)" has no Copilot inside PowerPoint or Word; "Microsoft 365
Copilot" does.

## 1. Storyboard to video

| | Corporate tools |
|---|---|
| Tools | Pair or Copilot Chat for the script and storyboard; Clipchamp to assemble, if enabled (TODO) |
| Working time | 45 to 60 minutes to a finished script and storyboard |
| Gate | Capacity throttling at busy times; no published figures |
| Can it finish? | **Partly.** No corporate tool was found that generates video clips. Copilot's video feature assembles existing or stock footage; it does not create new footage |
| Workaround | Record your own screen or camera for the scenes and assemble in Clipchamp. Generated clips need the personal track, with public content only |
| Caveat | Do not move work content to a personal account to get round this |
