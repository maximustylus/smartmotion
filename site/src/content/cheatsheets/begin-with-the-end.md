# Begin with the end in mind

Paste this before you ask for anything to be built.

---

I want to build [what, in one line]. Before writing any code or content, help me write a one-page brief with these headings, asking me one question at a time where you need my answer:

1. Purpose: who it is for and what changes for them when it exists.
2. Done means: three to five checks that must all be true before I call it finished.
3. Out of scope: what we will not build this time.
4. Constraints: platform, data rules, time, and anything that must not happen.
5. Phases: the order of work, with a stop for my approval after each phase.

Keep every line short. Mark anything you had to assume as TODO so I can confirm it. Do not start building until I say the brief is right.
