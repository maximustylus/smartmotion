# Build on solid frameworks

Paste this when designing a tool for teaching or assessment.

---

I am designing [the tool] for [learners] to [outcome]. Map it onto these frameworks, one at a time, and tell me where it fits and where it does not:

- Miller's pyramid: knows, knows how, shows how, does. Which level does the tool reach?
- R2C2: relationship, reaction, content, coaching. Which steps does the tool support in feedback?
- Zone of Proximal Development: what can the learner do with the tool that they could not do alone, and when should the help fade?
- Six Principles of Learning Design: which principles does it honour and which does it ignore?

Cite each framework to its original source, not a summary, and mark any claim you cannot source as TODO. Finish with the single change that would move the tool up one level on Miller's pyramid.
